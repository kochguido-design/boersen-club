# Börsen-Club

Eine kleine Familien-App, mit der Kinder Schritt für Schritt lernen, wie Unternehmen, Aktien und die Börse funktionieren, und in einem Musterdepot mit Spielgeld handeln.

- `index.html` – die App (eine Datei)
- `inhalt.js` – Lektionen und Firmen-Steckbriefe
- `skript/Code.js` – Server als Google Apps Script (Daten liegen in einer privaten Google-Tabelle)
- `skript/demo.js` – Demo-Modus im Browser: `index.html?demo`

Nur ein Lernspiel mit Spielgeld. Keine Anlageberatung.
